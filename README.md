# Moses O Fayele Portfolio (React, multi-page)
Edit all content in `src/data.js`, colours in `src/styles.css` (:root). Photo: `public/photo.jpg`.
Run: `npm install && npm run dev`. Deploy: push to GitHub, Settings > Pages > Source: GitHub Actions.
Add a page: create a component in `src/App.jsx`, add a `<Route>` and an entry in `nav` (src/data.js).
